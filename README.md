Personal Changes

Explain what you changed beyond the tutorial. Name the file, feature, asset, rule, or interface element.

I changed the game by giving each row of bricks its own color so the layout looks more organized and visually appealing. I also added background music to make the game feel more lively while playing. The music loops automatically so it never stops during gameplay. Another change I made was giving the bricks hit points instead of breaking in one hit. This means some bricks take multiple hits before disappearing. Their color and opacity change as they lose health. These updates make the game look better, sound better, and play with more challenge.
